# Aurora AI Core · 架构说明

Author: 晨星

## 分层总览

```
┌─────────────────────────────────────────────────────────────┐
│ L5  微指令层  verify.js · MicroEngine                         │
│     把算法执行分解为逐元素/逐步骤微指令，每步带不变量自动校验  │
├─────────────────────────────────────────────────────────────┤
│ L4  验证层    verify.js · Invariant Harness                   │
│     35 条数学不变量注册、执行、分组报告                        │
├─────────────────────────────────────────────────────────────┤
│ L3  深度学习  dl.js                                           │
│     Autograd(V 张量/14 可微算子) · MLP · Multi-Head Attention │
├─────────────────────────────────────────────────────────────┤
│ L2  机器学习  ml.js                                           │
│     PCA · GMM(EM) · k-Means · kNN · NB · 线性回归 · 逻辑回归 · CART │
├─────────────────────────────────────────────────────────────┤
│ L1  数值内核  num.js                                          │
│     Cholesky · Jacobi 特征分解 · SVD · logsumexp/softmax      │
└─────────────────────────────────────────────────────────────┘
```

依赖方向严格单向向下：`L5 → L4 → L3 → L2 → L1`。L1 不依赖任何上层。

## L1 数值内核（`src/num.js`）

全部为经典最优算法的直接实现，无自创近似。

| 能力 | 采用算法 | 关键性质 |
|---|---|---|
| Cholesky 分解 | Cholesky–Banachiewicz | 仅对称正定矩阵；`L` 下三角 |
| SPD 求解/求逆 | Cholesky + 前代/回代 | 比通用 LU 更稳定、更快 |
| 对称特征分解 | 循环 Jacobi 旋转 | 精度最高的经典方法之一，特征向量天然正交 |
| SVD | 对 `AᵀA` 做 Jacobi + `U = AV/σ` | 复用同一内核 |
| 稳定函数 | `logsumexp` 平移技巧 | 避免 `exp` 上溢/下溢 |

数值精度实测：`‖Av − λv‖ ≈ 2.3e-15`，`‖VᵀV − I‖ ≈ 2.2e-16`（双精度 `ε ≈ 2.2e-16`）。

## L2 机器学习（`src/ml.js`）

| 算法 | 经典来源 | 不变量 |
|---|---|---|
| PCA | Pearson 1901 | 协方差对称 PSD；主成分正交；投影方差 = 特征值 |
| GMM (EM) | Dempster et al. 1977 | 责任度每行 Σ=1；权重 Σ=1；对数似然单调不减 |
| k-Means | Lloyd 1957 / k-means++ 2007 | 惯性单调不增 |
| k-NN | Cover & Hart 1967 | k=1 时训练集零误差 |
| 高斯朴素贝叶斯 | Bayes 1763 | 后验 Σ=1 |
| 线性回归 | 正规方程 (Gauss) | 残差 ⊥ X（`Xᵀr = 0`） |
| 逻辑回归 | GLM / Nelder & Wedderburn 1972 | 解析梯度 vs 数值梯度 |
| CART | Breiman et al. 1984 | 预测在标签集内；叶节点纯度提升 |

## L3 深度学习（`src/dl.js`）

反向模式自动微分。核心是 `V` 张量（2D）+ 14 个**全可微**算子：

`matmul` `add`（含行广播）`addScalar` `sub` `mul` `scale` `sumAll`
`tanh` `relu` `exp` `log` `sig` `softmaxRowsV` `sliceRows` `transpose`

> **设计教训（已固化）**：任何「从 `.data` 读取数值再包成新 `V`」的写法都会生成**无父节点的叶子常量**，
> 使梯度链断裂、参数梯度恒为 0。这正是本项目开发中 MLP 不收敛、注意力梯度检验失败的根因。
> 因此转置、行切片、逐头投影等操作一律实现为可微算子，禁止在图外做数值搬运。

- **MLP**：`[2,6,2]` + tanh 可在 4000 epoch 内 100% 解 XOR（loss `0.695 → -0.000`）。
- **多头注意力**：Vaswani 2017 缩放点积；逐头投影后求和（数学等价于 concat + 单次投影，但梯度链完整）。
- **`gradCheck`**：通用梯度检验，清零参数梯度后解析 vs 中心差分，返回最大相对误差（实测 ~1e-9）。

## L4 验证层（`src/verify.js`）

`createHarness()` 注册不变量 → `run()` 全量执行 → 分组报告 + 退出码。
每条不变量返回 `{ok, detail}`，`detail` 打印实测数值，便于人工复核量级。

## L5 微指令层（`src/verify.js`）

`createMicro()` 提供微指令目录与执行记录：

- `defMicro(id, invariant, doc)` 定义原子操作及其数学不变量
- `record(id, inputs, output)` 执行即校验，写入 trace
- `report()` 汇总：微指令总数、通过数、失败数、按类型分布

运行时，一次 `microMatmul(A,B)` 会产生 `rows × cols` 条 `MAC` 微指令，
**每条都独立重算 `Σ A[i][k]·B[k][j]` 并与输出比对** —— 这是真正的逐元素可审计，而非事后抽查。

## 跨层契约

所有模块共享同一条契约：**对外暴露的 API，必须同时暴露其可被独立验证的不变量。**
新增任何算法，必须同时新增不变量并进入 `tests/run.js`，否则不视为完成。
